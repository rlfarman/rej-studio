## The short version

REJ Studio is a Next.js frontend over a curated gene database and a Python
optimization backend. You search a gene, pick a transcript, tune parameters,
and submit. The backend runs the sequence through
[DNAChisel](https://edinburgh-genome-foundry.github.io/DnaChisel/) with the
constraints you chose, and streams back the optimized sequence plus a report.

## The pieces

### Gene database

Human and mouse genes and their isoforms live in a read-only Postgres
database. Every transcript has its coding sequence, length, exon count, and a
handful of descriptive fields (gene symbol, name, Ensembl IDs, MIM, disease
associations). You can search by any of those — the database has a full-text
index plus a substring fallback so partial matches still work.

### The frontend

The UI is a server-rendered Next.js app. The homepage is the gene search;
each gene has a detail page that lists its isoforms; and the design tool is a
form you can open either from an isoform or on its own with a pasted
sequence. Favorites and recent searches are kept in the browser.

### The optimization backend

Submitting the design form sends your sequence and chosen constraints to a
Python service. That service:

1. Validates the input (length, alphabet, start/stop codons).
2. Builds a DNAChisel problem with the constraints you selected (codon
   optimization, CpG minimization, GC content, splice site avoidance, etc.).
3. Runs the solver.
4. Returns the optimized sequence, a per-constraint report, and diagnostic
   metadata.

The backend is stateless — each submission is independent. Long-running jobs
are tracked by an ID so you can close the tab and come back.

## What the optimizer actually does

DNAChisel is a constrained codon-optimization library. It doesn't "invent"
sequences — it searches for a coding-equivalent sequence (same protein) that
satisfies the constraints you picked. Think of it as rewriting the DNA
without changing the amino acids, while steering away from patterns you
don't want.

The constraints REJ Studio exposes are the ones most relevant for RNA
End-Joining design: cryptic splice site removal, CpG minimization, k-mer
complexity, GC content, and optional WGGW motif insertion. See
[the design tool page](/docs/design-tool) for what each one means in practice.

## What it does _not_ do

- It does not predict expression, stability, or immunogenicity.
- It does not validate the biology — if the protein you're encoding is
  toxic, the optimizer will happily optimize it.
- It does not store your submissions long-term. Results are available while
  the job is active; download them before closing the tab.
